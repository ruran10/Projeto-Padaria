<h2>📌 Sobre o Projeto</h2>

<p>
  Este projeto me deu a experiência de trabalhar com amigos e desenvolver em equipe, dividindo responsabilidades, alinhando ideias e resolvendo problemas na prática em um contexto escolar.
</p>

<h2>⚙️ Minha Atuação (Back-end e Dados)</h2>

<ul>
  <li>Desenvolvimento e apoio na lógica de funcionamento da aplicação no back-end.</li>
  <li>Estruturação, manipulação e organização dos dados utilizados pelo sistema e pelo fluxo de caixa.</li>
  <li>Integração das regras de negócio com o restante da equipe para manter o sistema funcional de ponta a ponta.</li>
</ul>
